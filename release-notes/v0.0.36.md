0.0.36 is on npm under the `next` tag, as 0.0.35 was: `npm install -g @agentorg/cli@next`. `latest` stays 0.0.15. It pins AgentComputer 0.0.41, as 0.0.35 did.

## What you meet

- **A reply that goes silent no longer holds an agent for good.** A model response that sends nothing for five minutes was already meant to be given up, but that could be lost, and the agent's turn then waited without end. It now holds: the conversation says "OpenAI couldn't be reached. Try again later." or "The response stream broke off.", and you can send again.
- **Stop ends the model request too.** Before, the agent stopped at once, but a request still waiting for OpenAI's first byte ran on until an answer began.
- **More of each request is read from OpenAI's cache,** with ChatGPT plan usage. Each model request now carries a key, a hash of the agent's id, so one agent's requests are kept together. The key holds no name and nothing you wrote. On a set of eight conversations, two runs each way, the share of input read from the cache went from 6–8% to 16–17%.
- **The lines that tell you to install or update AgentComputer** now say `npm install -g @agentorg/computer@next`. You meet them on a computer without the Mac app, when AgentComputer isn't installed or is older than AgentOrg needs. Without `@next`, npm installs a much older version.

## Built, and not yet met

- **A decision card.** `chat@1` now carries a card under an agent's reply, your answer to it, and a reaction on a message. No agent makes a card or a reaction yet, and the page draws none. A card can't be answered yet: an answer sent to an agent is refused.
- **Plugins inside an agent.** Each agent now has a place of its own for plugins, and a capability may be made of them. No agent holds a plugin yet, so nothing an agent is told or offered changes.

## What you need to do

- **A home from 0.0.35:** nothing. Going back to 0.0.35 hasn't been checked.
- **A home from 0.0.34 or earlier:** as when 0.0.35 opened such a home.
- **The install line** still installs nothing while no signed Mac app is published.

## Not run on a Mac

As before, the service under the real launchd, the install line, `agentorg update` and `agentorg uninstall` were checked with stand-ins. The silent reply, and a Stop before OpenAI's first byte, were shown with a stand-in for OpenAI, not with a real response that stalled.
