## What you meet

- **A decision comes as a card.** When an agent's reply leaves you a decision, it can put one to four choices under the reply, some with a line of detail. A tap answers, at once and for good: the card shows your pick, and no bubble is added for it.
- **Confirm, where it matters.** For what can't be undone, the agent asks you to confirm: your pick is held and can be changed until you press Confirm. Where several choices may be picked, the card has checkboxes and always confirms.
- **You can still just write.** Writing in the box instead leaves the card in place, passed over, with nothing picked. So does a newer card.
- **An emoji on your message.** A message that asks for nothing, such as "Thanks!", was already closed with no reply. The agent can now leave an emoji on it, so you see it was read. It notifies no one.
- **The card is the offer.** The agent is told not to also write the offer out, as in "want me to…?".
- **What it costs.** Each request of an agent's work is about 165 input tokens longer, and the request that says whose a message is, 39. On a set of eight conversations, two runs each way, the number of requests didn't rise (25 and 23, against 26 and 25). A card came only where a decision was left; "Thanks!" was closed with 👍 and no reply.

## Built, and not yet met

- **Several questions on one card.** The page draws them, each on a tab, answered together with one Confirm, and `chat@1` carries them. No agent is offered that form yet, so no card is expected to have tabs.
- **Memory.** A memory plugin is inside: a few short lines an agent writes itself and is told in every turn. The page doesn't offer it yet: it comes on offer with the words that tell the agent when to write a line and whose its lines are.
- **Plugins by name.** An agent now holds the plugins its settings name, loaded and unloaded as they change. No agent the page makes holds one, so nothing such an agent is told or offered changes. An agent whose record names a plugin this version doesn't carry is down, with the reason; that can only be a home last run by a later version.
- **`agents@1`** lets what an agent holds list its plugins, and be something you have no slots to. Only the Memory unit builds one, and the page doesn't offer it.

The card and the emoji were checked in two halves, not together: the page in a real browser over a stand-in for the service, and a real model through the service without the page. A real model's turn after a pick on its card was not measured.
